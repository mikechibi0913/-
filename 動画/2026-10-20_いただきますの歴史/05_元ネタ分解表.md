## 1. 元ネタの型と強度

- 型：**解説型**（主人公なし。ナレーターが「謎 → 手がかり → 答え → さらに奥」と歴史をたどる。外国人の声は第0章の問いと第7章の反応だけ）
- 強度：**レベルA寄り**（年号・資料名・出来事がはっきりある）。ただし「〜と言われます」「〜とされています」が多く、事実の確認はまだ。下の「事実の要確認リスト」に分けた
- 全体の文字数：9,500字（12区間）

## 2. 場面ごとの分解（4項目）

| 区間（字数） | ① 何が起きたか | ② 視聴者（「私たち」）はどう変わるか（前 → 後） | ③ 視聴者に何を残したか（分かったこと／疑問／まだ隠していること） | ④ なぜ次を見るか |
|---|---|---|---|---|
| 冒頭（247） | 「命への感謝ではなかった」と言い切って始まる。外国人がよく不思議がる言葉、学校では教わらない歴史、広まった場所は思いも寄らない所、世界の食卓と比べると珍しい、と予告 | 「いただきます＝命への感謝」と思っている → 「え、違うの？」 | 疑問：じゃあ何？ どこで広まった？／隠す：広まった場所・世界との違い | 「思いも寄らない場所」が知りたい |
| 第0章 命への感謝だけ？（821） | 給食で教わった「命への感謝」を確認 → でも説明がつかないことがある。外国人の問い「誰に向かって言っているの？」。人によって言い方・手の合わせ方が違う。言葉と習慣は別の歴史で、習慣が広まったのは意外なほど最近。広めたのは坊さんでも神主でも政治家でもない「ある場所」。平成に1通の手紙で論争になる | 知っているつもり → 「答えられない自分」に気づく（足元がゆらぐ） | 分かった：言葉と習慣は別物・習慣は最近／疑問：誰に言ってる？ なぜ人で違う？／隠す：ある場所・手紙の論争 | 謎が3つ（場所・手紙・誰に）並んだ。チャンネル登録の呼びかけ「この後、世界が驚いた本当の理由が分かります」 |
| 第1章 頭の上に掲げる（735） | 「頂く」の字の意味＝頭の上に乗せる。身分の高い人からもらう物を頭上に掲げた。もらうの謙譲語に。食べ物も額まで掲げてから食べた。「頂」は山のてっぺん。今も名刺を両手で受ける「押しいただく」に残る | 「命への感謝」→「もとは目上を敬う動作だった」（1つ目の反転・小） | 分かった：言葉の根は敬い／疑問：いつ食べることと結びついた？ | 章の終わりの問い「いつ頃なのでしょうか？」 |
| 第2章 狂言に残る言葉（760） | 室町の終わりの狂言に「食べる・飲む」をへりくだる「いただく」がある。身分社会で広がった。→「やっぱり古い伝統」と思わせて「まだ謎に答えていない」。昔の食卓は銘々膳・箱膳で、食前の言葉は家ごとにまちまち。ちゃぶ台は大正の終わり〜昭和の初め | 「やっぱり伝統なんだ」→「いや、まだ違う」（わざと納得させてから外す） | 分かった：言葉は古い・でも全国共通の習慣はなかった／隠す：いつ、どう共通になった？ | 「答えは多くの人が想像するよりずっと近い時代に」 |
| 第3章 記録が語ること（781） | 1891『子供の教え』→ 1904 国定の修身教科書「ご飯を食べる前にはお父さん、お母さんにいただきます」→ 1917 作法の手引き → 1934 資料。40年あまりで決まり事に。共通点は「どれも子どもへの教え」。柳田国男（1946）「近頃広まった」。1983 民博の共同研究（284人）「戦争へ向かった時代のしつけ・教育から」→ **答え：学校の教室** | 「伝統」→「近代の教育が広めた」（**最大の答え合わせ**・冒頭からの謎の回収） | 分かった：広めた場所＝学校／疑問：教室で何が起きていた？ | 「その教室で一体何が起きていたのでしょうか？」 |
| 第4章 教室で声をそろえて（1,116） | 修身＝一番大事な教科。1904の教科書の一文はこの教え。給食の始まり 1889 鶴岡・忠愛小学校（おにぎり・塩鮭・菜っ葉の漬物）。1923 国が給食をすすめる。1941 国民学校で一斉に食べ始める掛け声に。当番の「手を合わせてください」「合わせました」→ 今も続く光景。集団の規律・一体感の仕掛け。その世代が親になり家庭へ。ちゃぶ台と合う。→ 比較的新しい教育で整えられた | 「答え」→「自分の給食の思い出」と重なる（自分ごと・なつかしさ） | 分かった：給食の掛け声→家庭へ／隠す：ごちそうさまは？ | 「同じことは食事の後に言うもう1つの言葉にも言えます」 |
| 第5章 教科は消えても（1,141） | 「ご馳走」＝馬を走らせて食材を集める。走り回った人への感謝。いただきます（敬い）とごちそうさま（働いた人への感謝）は別の向き。1945 敗戦、12/31 GHQが修身を停止（軍国主義が入っていたため）。教科は消えたが習慣は残った。1947 ララ物資で給食再開（約300万人）。1946/12/24 贈呈式 → 学校給食感謝の日・1/24〜の学校給食週間。食べ物不足の時代の切実な感謝。学校給食法 | 「教育で作られた形式」→「戦後の切実な感謝で根づいた」（意味の重み↑・小さな感動） | 分かった：制度は消えても習慣は残る・感謝の重み／疑問：じゃあ命への感謝は？ | 「けれど、これでもまだ話は終わりません」 |
| 第6章 命への感謝の正体（936） | 冒頭の「人によって違う」に戻る（統計ではなく経験談と断る）。短期間で広まったから差が残る。では命への感謝は嘘？→ **そうではない**。八百万の神・自然の見方となじんだ。2006 新聞記事で「命をいただく」と語られ、同じ年に福井県の図書館が調べると古い記録はなかった → 広まる中で人々が見つけ育てた意味。いただきますは3つの顔（敬語・自然への敬い・近代の習慣） | 「命への感謝はウソだったの？」（谷）→「後から育てた本物の意味」（**冒頭の否定をひっくり返す反転**・安心） | 分かった：3つの顔／疑問：宗教と関係ある？ | 「では、この言葉は宗教と関係があるのでしょうか？」 |
| 第7章 世界の食卓と比べて（961） | 宗教かどうかは意見が分かれる（ただの作法説／民俗学の神人共食・直会／仏教保育園の食前の言葉）。世界：ボナペティ（周りの人が言う）、グーテンアペティート、ブラジル、韓国チャルモッケッスムニダ（作った人・ごちそうした人へ）、中国語にはない、キリスト教の祈り（神へ）。日本語を学ぶ外国人の驚き「誰に言っているのか分からない。なのに1人の時も言う」。同じ手を合わせても向かう先が違う | 「日本の中の話」→「世界から見ると珍しい」（誇り・にっこり）＝**冒頭の予告「世界の食卓」の回収** | 分かった：日本だけの形／隠す：手紙の論争 | 「この小さな挨拶を巡る議論は今も続いています」 |
| 第8章 給食費の論争（675） | 2005秋、ラジオ番組に手紙。「給食費を払っているのだから、いただきますと言わせないで」と申し入れた母親。反対の声が多く寄せられた。お金で払えるもの・払いきれないもの（育てた人・調理員さん・命）。この言葉は今も問い直され、変わり続ける。でも「やめるべき」という声は多くなかった | 「えっ？」とモヤっとする（小さな谷）→「やっぱり大切にしたい」（共感・うなずき）＝**冒頭の予告「1通の手紙」の回収** | 分かった：今も大切にされている理由／残り：冒頭の疑問の最終回答 | 「最後にもう1度、冒頭の疑問に戻りましょう」 |
| 最終章 小さな鏡（804） | 「なぜ人によって違う？」への答え＝3つの層の、どの顔を強く受け継いだかが違う。6文字に身分社会の記憶・自然への心・教室の声が重なる＝日本の歴史を映す小さな鏡。戦後の人々の祈りと今が一瞬重なる。「命への感謝」は間違いではなかった、その下に長い歴史。「誰に言っているの？」と聞かれたら → 目の前の食べ物にも、作った人にも、この一言を手渡してきた人たちにも。今日の食卓で歴史の続きが書き加えられる | 「知っているつもり」→「毎日の一言が深くあたたかいものに」（**一番上・余韻**） | 分かった：外国人の問いへの答え（第0章の回収） | （着地。まとめへ） |
| まとめ・考察（523） | 全体のおさらい。伝統は少しずつ意味を足しながら手渡されてきたもの。「日本人は自分の当たり前に、どれほど長い歴史が積み重なっているかに気づいていない」。コメントの問いかけ「いただきますの思い出や、外国の方に驚かれた経験は？」。チャンネル登録のお願い | 余韻 → 「自分の話をしたい」 | 問いかけ：自分の思い出 | （終わり） |

## 4. 元ネタ分析（04「元ネタ分析」①〜⑦）

**① 伸びた本質的な要因（3つ・しなちゃんの推定）**
1. **毎日言う言葉の「常識をひっくり返す」入口**：「命への感謝ではなかった」で、視聴者全員が持っている知識をゆさぶる。自分ごとになる
2. **謎の答えが「自分も通った学校の給食」**：遠い歴史ではなく、視聴者の子どもの頃の記憶（当番・手を合わせて）に着地する。なつかしさと驚きが同時に来る
3. **否定で終わらず、最後に肯定し直す**：「命への感謝は間違いではなかった。その下にもっと豊かな歴史があった」で、視聴者の思い出を傷つけずに、より大切なものにして返す（コメント1の「このまま継続でいいよね」と合う）

**② 構造・感情・情報**
- 構造：冒頭で謎を3つ（場所・手紙・世界）予告 → 言葉の起源（古い）→ わざと「伝統だ」と思わせる → 記録で「近代の学校」→ 給食の光景 → 戦後に根づく → 命への感謝の正体（肯定し直し）→ 世界と比べる → 手紙の論争 → 冒頭の問いに答えて着地
- 感情：ゆらぎ → へぇ → 納得しかけ → 外される → 答え合わせ（驚き）→ なつかしさ → じんわり → 不安（ウソ？）→ 安心 → 誇り → モヤっ → うなずき → あたたかい余韻
- 情報：年号と資料名がずっと続く（1891・1904・1917・1934・1946・1983・1889・1923・1941・1945・1947・2005・2006）。リアリティの柱

**③ 離脱せず見続けた理由（時系列）**
- 冒頭：言い切りの否定＋「思いも寄らない場所」
- 中盤：章の終わりにいつも問いを置く（「いつ頃？」「何が起きていた？」「宗教と関係ある？」）
- クライマックス：第3章「学校の教室でした」→ 第6章「ウソではない」
- 余韻：第0章の外国人の問いに、最後に答える

**④ コメント欄が伸びた理由**（コメントは3件だけなので推定。くわしくは 06 コメント欄の分析）
- 共感：「どんな始まりでも、命への感謝として続けたい」
- 自己投影：「ルーツなんて考えたことなかった」
- 対立：今の3件では見当たらない

**⑤ 再現できる型（勝ちパターン）**
「みんなが知っている当たり前の一言」→「実は違った（言い切り）」→「古い起源（わざと伝統と思わせる）」→「意外に新しい・身近な場所が広めた」→「その場所の光景（視聴者の思い出）」→「否定した常識を肯定し直す」→「世界と比べて日本だけ」→「現代の小さな論争」→「冒頭の問いへの答え＋あたたかい余韻」

**⑥ 反転の構造**
- 反転あり。種類と位置：
  - 第1章：命 → 敬い（小）
  - 第2章：「伝統だ」→「まだ違う」（フェイント）
  - 第3章：古い伝統 → 近代の学校（**最大**）
  - 第6章：「ウソだったの？」→「後から育った本物の意味」（**冒頭の否定をひっくり返す**）
- 強さ：第3章は強い。第6章は「安心」の反転で、余韻につながる
- 強化できるか：設計サマリー（5-3）で検討する（TTPなので、位置と順番は変えない）

**⑦ 競合・不足**
- 同じ元ネタの版が4本あり、回ったのは基準原本の1本だけ（02_関所.md 再判定）
- 外国人の反応は第0章と第7章だけ。チャンネル名・タイトルの【海外の反応】に対して少ない

## 5. 弱点分析（04「元ネタの弱点分析」）

| 弱点 | どこ | なぜ弱いか | どう超えるか（案・設計サマリーで決める） |
|---|---|---|---|
| 説明が続く | 第2章後半（箱膳）・第3章（年号の連続）・第5章前半 | 年号と資料名が続き、気持ちが動かない区間がある | 年号の間に「子どもが言われた一言」など小さな場面を1つ置く（原則9）。順番は変えない |
| 感情から切れる | 第7章前半（宗教の説） | 説がならぶだけで、視聴者の気持ちがない | 第7章後半の外国人の驚きにつなぐ1文を早めに |
| 誤字・言いまちがいの多い文字起こし | 全体（「カ主」「移す鏡」「荷物への感謝」など） | 文字起こしの誤りか、ナレーションの誤りかは不明 | 本編は自分の言葉で書くので、正しい言葉で書く |
| 本当かどうかの確かさ | 第0章・第6章「地域によっては手を合わせない」 | 元ネタ自身が「統計ではない」と断っている | 同じく断り書きを残す |
| 冒頭の言い切り | 冒頭「命への感謝ではなかった。」 | 最後に「間違いではなかった」と言うので、言いすぎに聞こえる人がいる | サムネの「!?」と同じく、言い切りすぎない形を検討（ただし冒頭のフックの形は残す） |

- 視聴者心理のギャップ：元ネタは「意外な歴史への驚き」を与えようとしているが、コメント1は「どんな始まりでも感謝で続けたい」と、**驚きより「肯定」**を受け取っている（推定・3件だけ）
- 超えるためのルール（3つ）：
  1. 年号・資料が2つ続いたら、次に「人の場面か、視聴者の思い出」を1文入れる
  2. 否定（「〜ではなかった」）を書いたら、同じ章か次の章で「でも大切なのは変わらない」に戻る道を見せる
  3. 外国人の問い「誰に向かって言っているの？」を、第0章・第6章・最終章の3か所で同じ形で出す（元ネタは第0章と最終章の2か所）→ これは「変える所」になるので、設計サマリーでまほ社長に聞く
- この動画で持ち帰るもの（一文）：**毎日の「いただきます」は、何百年もの人々が少しずつ意味を足して手渡してくれた、日本の歴史の続きである**

## 6. 事実の要確認リスト（執筆の前に確かめる）

確認済み（しなちゃんの知識・推定に近いので、執筆前にもう一度確かめる）：
- 1889年 山形県鶴岡町・忠愛小学校で給食が始まった（おにぎり・塩鮭・漬物）
- 1945年12月31日 GHQが修身・日本歴史・地理の授業停止を指令
- 1946年12月24日 ララ物資の贈呈式 → 学校給食感謝の日／1月24日〜30日が全国学校給食週間
- 1954年 学校給食法（元ネタの「4年」は「昭和29年」か「1954年」の聞き取りまちがいと推定）

不明（調べてから使う）：
- 1891年『子供の教え』という本と、その一節
- 1904年の国定修身教科書の文「ご飯を食べる前にはお父さん、お母さんにいただきます」
- 1917年の作法の手引き・1934年の資料
- 柳田国男が1946年の本で「近頃広まった」と書いたか（書名）
- 1983年 国立民族学博物館の共同研究・284人
- 2005年秋のラジオ番組の手紙（番組名は元ネタに出てこない）
- 2006年の新聞記事と、福井県の図書館の調べ
- 1947年1月 約300万人で給食再開
