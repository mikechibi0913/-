## 元ネタ分析（04 指示文 ①〜⑦）

### ① 伸びた本質的な要因（3つ・推定）
※今回の元ネタは自分のチャンネルでは約0.6倍で、当たっていない（関所）。同じ企画は14本中12本が回っている。下の要因は「企画が当たる理由」と「この元ネタの物語の良さ」を分けて書く
1. **企画の力（推定）**：「30年前の日本の曲が、今になって世界で聴かれている」という時間ギャップ。視聴者（50代以上）が若い頃に聴いた曲が、海外の若い人に届いている＝自分の青春がほめられる誇り（日本人の視聴者の自己投影）。同じ企画の14本は、解説型（10〜17分）でも物語型でも回っている
2. **物語の良さ**：理由を「データ・専門家」で探して分からず、日本の「名もない人の日常」で答えを見つける。答えが「すごい技術」ではなく「急がない」「特別扱いしないで聴き続ける」なので、自慢にならない（チャンネルの芯「名もない人の、名もない行い」と合う）
3. **主人公の悩みと答えが重なる**：バズ・フォロワーに疲れた人が「急がない音楽」に救われる。今のSNSに疲れている人（視聴者）にも届く（推定）

### ② 構造・感情・情報
- 構造：予告 → 主人公の紹介 → 通勤電車で出会う → 30年前と知る → 調べる（データ・専門家）→ 分からない → 日本へ → 大阪で3人（レコード店・青年・公園の女性）→ 福岡の手がかり → 屋台 → 堤防で涙 → 帰国・プレイリストを変える → 締め
- 感情：心が大きく動くのは #3（胸がざわつく）、#4（30年前）、#9（曲は変わっていない）、#11（くすっ・急がない）、#13（変わったのは私）、#16（屋台の温かさ）、#17（涙・いちばん上）、#19（コメントが変わる）
- 情報：ランキング・カバー・コナン・コード進行・お蔵入りの話・真夜中のドア・シティポップ・ユーミン・松田聖子・福岡出身

### ③ 見続けた理由（時系列・推定）
- 冒頭：「一体何が起きているのか」「あの感覚の正体」を隠す。曲名（スピッツ）は冒頭で出さない（タイトルで分かっている）
- 前半：曲名・30年前（#4）までが約2分半と早い。サムネ・タイトルの約束を早めに回収している
- 中盤：大阪の3人が、それぞれ別の答えのかけら（変わっていない／飽きない／変わったのは私）を出す。ただし3人とも「静かに語る → フレイヤが心で感じる」の同じ形
- 後半：福岡の屋台（くすっ・温かい）→ 堤防（涙）
- 余韻：プレイリストを変える（行動）・コメントが変わる

### ④ コメント欄が伸びた理由（5件・くわしくは 06）
- 共感：「日本の曲は8小節歌っても同じ音符を繰り返さない」「日本人は想像のストーリーで歌詞を作れる」（ニコラス・エドワーズさんの話）＝日本の曲の作りへの誇り
- 対立：「ロビンソンと空も飛べるはずの話がごちゃごちゃ」（事実の指摘）／「まだやっているんだ😅」（同じ企画への冷めた目）
- 自己投影：「浜田省吾はなぜ海外で反応されないのか」（自分の好きな歌手の話）／ブルーノ・マーズがロビンソンを挙げた話

### ⑤ 再現できる型
「数字や評判に疲れた外国の“選ぶ人” → 日本の古い曲に理由の分からない感動 → データや専門家では答えが出ない → 日本に来て、名もない人たちが特別扱いせず日常で聴き続けている姿に出会う → その曲を歌う人の育った土地で、もう一度聴いて涙 → 自分の選び方（仕事・趣味）を変える」

### ⑥ 反転構造
- 反転あり。2つ（どちらも弱め）
  - 1つ目（#3→#4）：新しい曲だと思った → 30年前の曲。強度：中（タイトル・サムネで予告済み）
