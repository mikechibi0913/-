# 関所（まほ社長のチャンネル用）

作成：2026-10-15 しなちゃん（学習文3通目のステップ4で、まほ社長と決めた）
元：`しなちゃん資料/06_制作の流れ.md` STEP -1、`08_制作フロー.md` ①、`14_競合分析.md` の表
注意：元の資料は変えていません。ぶつかったときは、この関所を使います。

関所＝「この元ネタで作っていいか」を、作り始める前に決める門。

---

## いつやるか

元ネタ・参考URL・企画・タイトル・サムネの相談が来たら、**ほかの作業より先に必ずやる**。まほ社長に言われなくても、しなちゃんから始める。
判定を出して、まほ社長の返事をもらうまで、元ネタの保存・コメント分析・タイトルづくりに進まない。

## 手順

### 1. まほ社長に先に聞く
「先に⭕△❌と理由を一言どうぞ」と1回だけ聞く（まほ社長が自分で判断する練習）。答えがなくても、関所は進める。

### 2. 3つの質問

**① 何の話か**（仮・2026-10-15）
- ⭕：食べ物・日常生活・言葉や文化の話（都道府県の英訳など）

**② 見たあとの気持ち**（仮・2026-10-15）
- ⭕：ほっこり・くすっと笑える（「日本っていいな」とにっこりする）
- ❌：病気・医療・余命／職人・技術の自慢／スポーツ／号泣・感動で押す／国・政治・経済・ニュース／スカッと・ざまぁ
- 新幹線：体験談の中で、比べる材料の1つとして出すならOK。サムネや企画の主役が新幹線の技術比べなら❌

**③ もうやった話じゃないか**
- 比べる相手：**まほ社長の公開済み動画**。関所のたびに、最新の一覧を取り直す
  - 一覧の取り方：`https://www.youtube.com/feeds/videos.xml?channel_id=UCGeCfOCWRKKBoeo5TLg4mGA`（新しい順に15本まで。16本をこえたら別の取り方を考える）
- `16_競合データ_動画.json` の健志さんのチャンネルの動画（`own: true` の118本）は参考だけ。③には使わない
- ❌：出来事も順番も同じで、国籍や料理だけ替えたもの／題材だけ残して、面白さが変わったもの
- ⭕：当たった動画の「変化の面白さ」を残して、今回だけの出来事を新しく作ったもの
- 通す条件：次の2行を **まほ社長が先に書く**。しなちゃんは厳しめに見る
  - 引き継ぐ面白さ（誰が何に困り → 何がきっかけで → どう変わるか）
  - 今回だけの出来事（1行で具体的に。書けなければ❌）
- 「面白さを残しただけ」を、作り直しの言い訳にしない

### 3. 同じ元ネタの全バージョンを数える
- `16_競合データ_動画.json` を、タイトルのキーワードで検索する
- 「同じ元ネタの全バージョン」＝同じ企画・同じ元ネタを **はっきり元にした** 別の投稿や後発動画。題材が似ているだけの動画は入れない
- 出すもの：全バージョンの再生数／何本中何本が回ったか／当たった1本のあとに出た後発の結果
- 「回った」＝そのチャンネルのいつもの再生数（`med`）の3倍以上。「回らなかった」＝3分の1以下（`14_競合分析` と同じ物差し。`ratio` の値で見る）
- 回った率が平均（46%）より低い、または後発が全部回っていなければ △

### 4. 判定
- 1つでも❌なら ❌
- △は❌あつかい。まほ社長が理由をつけて「それでも作る」と言うまで、先に進まない
- 判定の根拠を必ず添える。「たぶん大丈夫」で通さない
- 根拠に使うもの：`14_競合分析` の 2026-10-06 の表、`16`〜`20` の競合データ

### 5. 数字の出し方
- 数字は必ず「数字／比べた相手／何倍か／何を判断する数字か」の4つをセットで出す
- 確かめられないことは「確認済み／推定／不明」に分けて書く。分からないものを⭕にしない
- 競合データはライバルの数字。まほ社長のチャンネルに当てはまるかは「不明」と書く

## 判定の形（毎回この形で出す）

| 質問 | 判定 | 理由 | 数字（4つセット） |
|---|---|---|---|
| ① 何の話か | ⭕／△／❌ | | |
| ② 見たあとの気持ち | ⭕／△／❌ | | |
| ③ もうやったか | ⭕／△／❌ | 2行（引き継ぐ面白さ／今回だけの出来事） | |
| 全バージョン | ⭕／△／❌ | 何本中何本が回ったか・後発の結果 | |
| **まとめ** | **⭕／❌** | | |

## 「仮」について

①と②は、まほ社長のチャンネルの記録がまだ少ないので **仮** で決めた（`01_芯.md` Part 3：数本たまってから決める）。
投稿の記録がたまったら、学習文7通目の「当たった動画・外れた動画の記録表」を見て、まほ社長と見直す。
