【1. 冒頭文】
📖 読む：04「冒頭文の設計指示」／05 チェック15・19-19〜19-20・19-28〜19-29・19-44・19-51〜19-56・19-63〜19-66
💾 保存：11_冒頭文.txt
冒頭文は、映画の予告編です。本編がないと書けないので、本編が完成してから書いてください。
・1行目は、タイトルかサムネの言葉で、短く止める。
・2行目は、一番の驚きか、話題になっていること。説明にしない。「事実」と「矛盾」の2行に分けると、事件性が出る。
・人物の紹介は、4行目以降に、短く。
・1行は短く（最長30字、平均20字が目安）。ただし、全部を同じ短さにしない。
・本編で一番盛り上がる場面（クライマックス）のセリフや、結末は入れない。
・本編の途中の種明かしも、先に言わない。「なんで？」は本編まで取っておく。
・年齢・職業・会社名などを、一度に並べない（履歴書にしない）。
・「衝撃の結末」など、本編にそれだけの展開がない強い言葉は使わない。
・タイトルの言葉と、温度をそろえる。
書いたあとの確認（結果を見せてください）
・冒頭文が触れている本編の章を、全部書き出す
・クライマックスの章の内容が入っていないかを確認する
・冒頭文で約束したことを1つずつ書き出して、本編のどこで回収されているかを確認する
（しなちゃんが足した）04 の「固定文（それでは一緒に、この物語を見ていきましょう）」と「フック直後の TikTok などの映像素材」は、使うかどうかをまほ社長に聞いて決める。
→ 決まったこと（2026-10-17 まほ社長）：固定文は使わない。TikTok などの映像素材も使わない（読みかえ表 4）。

【2. 挨拶文】
📖 読む：04「視聴者への挨拶文」（浅田さんのチャンネルの5行の形。参考）
💾 保存：12_挨拶文.txt
・形（行数・言葉づかい）を、まほ社長と一緒に決めてください。決まったら設定ファイルに書いて、毎回同じ形を使います。
・変えてよいのは、質問文の1行だけ。短い1文で、本編の「答え」に合っているか確認してください（見守る側の人もコメントしやすい質問に）。
→ 決まった形（2026-10-17 まほ社長。「47都道府県の英訳」の公開済みの形に、質問文を1行足した6行）。2行目の質問文だけを毎回変える
```
最後までご覧いただき、ありがとうございました
（質問文）
名もない行いを名もないまま、世界に伝える
それが、このチャンネルの役目です
よろしければ、チャンネル登録と高評価をお願いいたします
今日も、あなたの一日がこの国の一日でした
```
→ 追加（2026-10-24 まほ社長）：挨拶文はパターンAとBの2つを置いておく。上の6行が **パターンA**、下の4行が **パターンB**。どちらも変えるのは問いかけ（質問文）の1行だけ。どちらを使うかは、動画ごとにまほ社長に聞く
- パターンA：上の6行（2026-10-17）
- パターンB（2026-10-24。1行目の問いかけだけを毎回変える）
```
（問いかけ）
コメント欄で、あなたのお話を聞かせてください
世界がハマった日本を、これからも一緒にのぞいていきましょう
高評価とチャンネル登録で、応援してもらえるとうれしいです
```
