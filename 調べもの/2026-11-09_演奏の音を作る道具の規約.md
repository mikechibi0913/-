# 演奏の音を作る道具の規約（2026-11-09）

目的：蛍の光の音楽隊（`動画/2026-11-09_蛍の光の音楽隊/`）の【BGM案 無音（クラリネットだけ）】【BGM案 無音（クラリネットとバグパイプだけ）】の試しの音を作る

## 1. 楽器の音：FluidR3_GM（Fluid Soundfont）
- 手に入れた所：Ubuntu の公式パッケージ `fluid-soundfont-gm` 3.1-5.3（2026-11-09 apt から取得・確認済み）
- 作った人：Frank Wen（2000〜2002, 2008）
- 規約：**MITライセンス**（パッケージの copyright ファイルを読んだ・確認済み）
  - 「無料で、制限なく、使う・コピー・変える・公開・配布・**販売**してよい」
  - 条件：ソフト（音のファイル）そのものを配るときは、著作権の表示とこの許可の文をつける
  - 保証はない（何かあっても作者は責任を持たない）
- しなちゃんの読み：
  - 作った音（WAV）を YouTube の動画に入れるのは、MIT の範囲で使ってよい（推定）
  - 音のファイル（サウンドフォント）そのものは配らないので、表示の条件は当たらない（推定）。気になるなら、概要欄に「楽器の音：FluidR3_GM（Frank Wen・MIT License）」と書けば安心
- 楽器：クラリネット（General MIDI の72番）・バグパイプ（110番）が入っている

## 2. 音にする道具：FluidSynth
- Ubuntu の公式パッケージ `fluidsynth` 2.3.4（LGPL）。道具なので、作った音には規約はかからない（推定）

## 3. 曲：蛍の光（オールド・ラング・サイン）
- 旋律はスコットランドの古い民謡（18世紀）。著作権は切れている（推定・一般知識）
- **注意：閉店の音楽「別れのワルツ」（3拍子）は、別の人が後から作った編曲**。こちらは著作権が残っている可能性がある（不明）→ **使わない**。作るのは、本編のとおり **元の4拍子の旋律** だけ
- 本編の第8章「ふだんの半分ほどのゆっくりした旋律」に合わせる

## 4. わからないこと
- 作った音が、動画で使える質かどうか（聞いてみないと分からない）
- YouTube の「Content ID」で、ほかの人が登録した「蛍の光」の演奏とまちがえられる可能性（不明。自分で作った音なので、もしまちがえられても異議を出せる・推定）
