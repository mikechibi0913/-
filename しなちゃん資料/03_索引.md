## 3　印の一覧（マホちゃん用に変える所）

### A　シナリオ制作指示文（04）
| 場所 | 内容 | どうする |
|---|---|---|
| チャンネルコンセプト | 「日本の静かな真実」の構造（外国人が見下す→日本人は語らず→主人公が崩れる） | マホちゃんのチャンネルの芯（芯の資料 Part 3）で置きかえる。まだ決まるまで参考扱い |
| ジャンル設定 | 「国籍・職種は変更しない。名前はオリジナル」 | ⭕そのまま |
| ターゲット設定・ゴール・感情状態A/B/C | 68歳・男性・定年退職・晩酌 | マホちゃんの視聴者が分かるまで「仮」。投稿後の記録表で確かめる |
| 日本人キャラクターの設計ルール／「当たり前型」／重要ルール | 日本人は語らない、自慢しない | このチャンネルの武器かどうかは未確認。マホちゃんの元ネタ（都道府県の英訳）は、大槻さんが語る解説型なので当てはまらない場面もある。元ネタを見て決める |
| ヒーロージャーニー「偏見の層」 | 「アジアを遅れていると思い込む」 | マホちゃん用に書きかえ |
| 解説動画の場合 | まとめ型に1本の糸 | ⭕マホちゃんの元ネタで一番使う |
| エンディング設計 | 「日本で学んだことが主人公の国で実を結ぶ」 | 元ネタに合わせる（今回は国連の場面で締めている） |
| ツァイガルニク設計 | 空白1.2秒・字幕3語以内 | 動画編集の話。読み飛ばす |
| 間でセリフを刺す | 「…」は自動動画で1秒の無音 | 彩子が動画を作るので⭕。書き方（「〇〇…」を基本）は共通 |
| 文字数 | ナレーターさんなら10,000字まで | マホちゃんは元ネタ±10%だけ |
| 出力ルール | 本編は常体・句点で改行・章の間に空行なし・テキスト出力 | 文末（常体／です・ます）はマホちゃんと決める。改行は編集で使うので、聞いてから決める |
| 冒頭文の固定文・フック直後の映像 | 「それでは一緒に、この物語を見ていきましょう」／TikTokの驚く映像素材 | マホちゃんの冒頭の形に合わせる。まだ使うかを聞く |
| 視聴者への挨拶文の固定構造 | 5行構造 | マホちゃんの挨拶文の形を決めてから（「名もない行いを…」の形など） |
| 本文中の「健志さん」 | 決定の経緯 | 「マホちゃん（またはマホちゃんチャンネルの運営者）」と読みかえる |
