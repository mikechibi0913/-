## 禁止事項 — 二度と同じミスをしない 必読

2026-09-27 整理：同じことが2〜3か所に書いてあったものは、詳しい説明を1か所にまとめ、ここは短くした（健志さんの言葉はそのまま残している）。

NG① タイトルの構造（小僧）を変える

失敗例：「日本で育つ外国人キッズの成長が尊すぎる！」
→ 「ダメダメ！小僧は変更しないでワードを変更して考えるようにして！」
詳しくは「タイトル」タブ。

NG② フック文3案が似たようなパターン

        3案が全て同じような表現・ポジティブ系だった失敗例あり。

        → 「三つとも同じようなフック文になっていますよ！」

        3案は必ず全く異なるアプローチで制作する。

        2026-09-23追記：リサーチシートで、記号や1〜2文字だけ違う3案が多数見つかった。これも同じ案。3案は型を変える。

NG③ フック文が全てポジティブ

        ポジティブなフック文は弱い。ネガティブ・逆張りが必須。

        → 「強ワード、ネガティブワード、逆張り、ギャップはある？」

        フック文には必ずネガティブ要素か逆張りを入れる。

NG④ 答え・感想を先に言う／逆張りを説明しすぎてネタバレ

→ 「そこまで説明したら、ネタバレしているからクリックされない」
「食うしかねーだろ」5,441回 ⇔ 「食うわけねーだろ」118万回。詳しくは「フック文」タブの滑る型「答え・感心を言ってしまう」。

NG⑤ 元ネタのサムネ画像・動画のスクショを加工して使う 更新

        元ネタの画像から文字を消して同じ人物のまま使うのは、「型」ではなく「コンテンツそのもの」のコピー＝パクリ（講座コラム⑩）。

        → まねるのは型（人数・表情・構図・場所・赤丸や矢印）だけ。画像は新しく作る。

        ※以前は「人物を変えるのは絶対NG」だったが、2026-09-23に健志さんの決定で逆に変更した。

NG⑥ 案Aのフック文が元ネタと全然違う構造になる

→ 「元ネタのフック文と全然違うのはなぜですか？」
案A（元ネタ寄せ・滑り止め）は元ネタの構造をコピーしてワードのみ変える。案B・Cは刺さる型で新しい見せ方を作ってよい（「フック文」タブ）。

NG⑦ 見下しセリフをそのままフック文にする

「日本の包丁なんてオモチャだw」5,527回など。例外も含めて「フック文」タブの滑る型に。

NG⑧ よそで当たった話をマネする・同じ話（題材）を使い回す 更新

        「これは国歌じゃない」最初59万 → マネ3,481回。「196ヵ国で日本だけ！」108万 → マネ4,582回。一度見た話に視聴者は？を感じない（マネが滑るのは5組のチャンネルで確認）。

        確定（2026-09-23・⑥⑦⑧⑩⑪⑬で確認）：落ちる原因は「同じ言葉」より「同じ話（題材）」。

        ・同じ話のくり返しは、最初が大当たりでも4分の1〜40分の1まで落ちる：「この差は一体何なんだ？」（中国と日本のインフラ比べ）212万 → 5,091、「いつまでトロトロ走ってるんだ!」（サムネまで同じ）9.6万 → 2,403

        ・言葉の形が同じでも、話が毎回新しければ当たる：⑬の「本当にコレに〇〇の…？」は約10回使って57万・47万・33万・32万・31万・21万（鉄道オタク・温泉・施設の食事・旅館・給食・寿司屋と毎回ちがう話）

        → 型・言葉の形はマネしてOK。話（誰が・どこで・何を）は必ず新しくする。自分のチャンネルで当たった話も使い回さない。

        ・国や品物を入れかえただけでは新しい話にならない（⑭で確認）：「貧乏な日本人と結婚するから…」をアイスランド→カナダ→スウェーデン→フランスで10万 → 1万、「〇〇が皆を狂わせた」をトイレ→コタツ→毛布→猫で11万 → 1万。骨組み（誰が・何をされて・どうなる）を変える。

        ・擦る場合の目安（⑩⑪⑬⑭）：2回目は1回目の3分の1〜4分の1でも、平均以上が多い。3〜4回目で平均を割る。

        ・マネは元を超えない（14チャンネルで0本） → 2026-09-23訂正：チャンネルの大きさが違うものを比べただけで、根拠にならない。講座の方針「タイトル・サムネの言葉はほぼ同じでOK」を優先。

        ※2026-09-23に一度「同じ言葉は必ず落ちる」と確定したが、⑬の分析で「同じ話」が原因と分かり書き直した。

        2026-10-06追加：サムネの使い回しも同じ。よそのサムネをほぼそのまま使った6例は、先に出た方が3.8〜17倍、後から出した方が0.09〜0.32倍（「サムネ画像」タブ⑬）。

NG⑨ 重い病気・泣きをフック文にする

「今すぐ飛行機を降りてください」791回など。例外（「日本に行きたい」という願いの言葉）も含めて「フック文」タブの滑る型に。

      2026-10-06：ライバル42chの最近4か月でも、病気・医療の話は17本中1本しか回らなかった（6%）。

NG⑩ サムネが「顔1人だけ」「ふつうの表情」「子どもが嫌がる・泣く顔」 NEW

ドラマ型15ch・149枚で、顔1人だけ19%、ふつうの表情19%、子どもが嫌がる・泣く顔22%（2026-10-06）。家族やまわりの人を入れて2〜3人以上、表情は驚き・笑顔に。詳しくは「サムネ画像」タブ⑬。
